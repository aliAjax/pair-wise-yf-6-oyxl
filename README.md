# 家庭维修当日排线

端口规划：`5114`

```bash
npm install
npm run dev
```

## 功能

两名师傅（王师傅、李师傅）09:00 开工、18:00 收工，前后两单之间留 20 分钟路程。
台账预置五项检修，每项登记小区、施工分钟、最晚完成时刻和加急标记。

- 加急项尽量早排，原来占位的普通项自动往后顺延；
- 逐单派给最早空出的师傅，赶不上最晚完成时刻或收工时刻的留待派，并说明冲突原因；
- 调整顺序、加急标记或任何字段后，路线、完成时刻和待派数立即重算；
- 数据写入 localStorage，关掉页面再打开仍在。

## 文件分工

| 文件 | 职责 |
| --- | --- |
| `src/scheduler.js` | 排线规则（纯逻辑）：优先级、路程、最晚时刻、收工判定、待派冲突 |
| `src/storage.js` | 存档：预置五项、localStorage 读写与异常兜底 |
| `src/main.js` | 页面：台账登记/调序、路线与待派展示、事件交互 |
