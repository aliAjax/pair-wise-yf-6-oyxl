# 家庭维修事项 · 当日上门排线

端口规划：`5114`

```bash
npm install
npm run dev
```

第二版：台账升级为两名师傅的当日派单排线板。

- 预置五项检修，登记小区、施工分钟、最晚完成时刻与加急标记
- 师傅 09:00 开工、18:00 收工，前后两单留 20 分钟路程
- 加急项尽量早排，普通项按占位顺序顺延；赶不上最晚时刻的单子留待派并说明冲突
- 调整顺序 / 加急标记后，路线、完成时刻与待派数即时重算
- localStorage 存档，关掉页面再打开数据还在

业务文件分层：

- `src/scheduler.js` 排线规则（作息、路程、加急优先、冲突判定）
- `src/storage.js` 存档（预置数据与 localStorage 读写）
- `src/main.js` 页面（登记、调整顺序、路线与待派展示）
